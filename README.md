# 11 «А» Photobooth

11 «А» сыныбына арналған браузерлік фотобудка: камерадан төрт кадр түсіреді, стикерлер мен рамка қосады, дайын фотолентаны PNG ретінде сақтайды немесе жүйелік Share мәзірі арқылы бөліседі.

## Іске қосу

Жобаны кез келген статикалық HTTP серверімен ашуға болады. Windows-та `run.bat` файлын іске қосыңыз.
